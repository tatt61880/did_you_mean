# もしかしてサイトスワップ

ジャグリングできないサイトスワップから、よく似た成立する候補を探すツールです。

[ツールを開く](https://tatt61880.github.io/did_you_mean/)

1 字の削除・変更・挿入・移動、または 2 字の交換で候補を探します。
たとえば `551` から、`51`・`531`・`5551` などが見つかります。

## 使い方

1. サイトスワップを入力して「検索」を押します。例のボタンからも入力できます。
2. 候補のボール数と、入力からの変更内容を確認します。
3. 「動きを見る」で、[@yuji_k64613 さんの JuggleMaster JavaScript 版](https://yuji-k64613.github.io/jmjs/jmjs.html)を開けます。

候補のコピーや、検索 URL の共有にも対応しています。

## 対応範囲

- `0`〜`9`・`a`〜`z`で表す通常のサイトスワップが対象です。
- 同時投げ・マルチプレックスには対応していません。
- 探索範囲は限定しており、上記の操作で成立するすべての候補を列挙するものではありません。
